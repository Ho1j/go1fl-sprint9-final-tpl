# Поиск максимального значения

Программа генерирует 100 миллионов положительных целых чисел и сравнивает
последовательный поиск максимума с поиском в восьми горутинах.
Оба поиска используют один и тот же слайс. Время выводится в микросекундах;
соотношение времени зависит от оборудования и текущей нагрузки.

```sh
go run .
```

Для пустого слайса обе функции поиска возвращают 0. Генератор при нулевом
или отрицательном размере возвращает пустой слайс (`nil`). Поиск также
поддерживает отрицательные числа и не изменяет входной слайс.
Последняя из восьми частей включает остаток от деления длины слайса.
Результаты горутин читаются после `sync.WaitGroup.Wait()`.

## Проверки

Требуется Go 1.24.1 или новее. Для локального запуска детектора гонок нужен
C-компилятор, совместимый с Go; на GitHub проверки запускаются автоматически.

```sh
go test -cover ./...
go test -race ./...
go vet ./...
```

Тесты проверяют генератор, пустые слайсы, один элемент, повторы, отрицательные
числа, границы типа `int`, остаток при делении на восемь и совпадение результатов
двух алгоритмов на слайсах разных размеров.
